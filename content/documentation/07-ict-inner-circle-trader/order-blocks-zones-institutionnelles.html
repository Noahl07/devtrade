Qu'est-ce qu'un Order Block ?

Un Order Block (OB) est la dernière bougie allant à contre-sens juste avant un mouvement impulsif institutionnel. C'est la zone où les institutions ont placé leurs ordres massifs — et vers laquelle le prix revient souvent pour "remplir" les ordres restants.

En termes simples : JPMorgan doit acheter 10 milliards d'EUR/USD. Ils achètent progressivement pendant que le prix baisse (bougies baissières) jusqu'à avoir accumulé leur position, puis laissent le prix monter. La zone de ces dernières bougies baissières avant la montée = l'Order Block bullish.

Order Block Bullish

Dernière bougie baissière avant une impulsion haussière qui casse la structure (BOS).

Order Block Bearish

Dernière bougie haussière avant une impulsion baissière qui casse la structure (BOS).

Critères de validation d'un Order Block

  1. Présence d'un BOS ou CHoCH après l'OB — sans mouvement impulsif qui casse la structure, ce n'est pas un OB institutionnel
  2. Liquidity sweep idéalement avant le départ — l'OB est plus valide si un stop hunt a précédé
  3. Fair Value Gap créé lors de l'impulsion — confirme que le mouvement était réellement institutionnel
  4. L'OB n'a pas encore été mitigé — une fois le prix revenu sur l'OB et reparti, il perd de sa valeur

Le Breaker Block

Un Breaker Block est un OB qui a échoué — le prix est passé à travers. Un OB bullish cassé devient un Breaker Block bearish (résistance). Un OB bearish cassé devient un Breaker Block bullish (support).

Les traders qui avaient acheté sur l'OB bullish sont maintenant en perte. Quand le prix revient sur ce niveau, ils veulent sortir au breakeven — créant une pression vendeuse qui transforme l'ancien support en résistance.
