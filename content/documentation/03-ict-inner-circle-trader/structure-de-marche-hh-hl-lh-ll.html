La structure de marché — le langage du prix

Avant de chercher un Order Block ou un FVG, vous devez répondre à cette question : "Qui contrôle actuellement le marché — les acheteurs ou les vendeurs ?" La réponse se lit dans la succession des sommets et creux significatifs.

Les 4 éléments de structure

  • HH (Higher High) : sommet plus haut que le précédent → structure haussière
  • HL (Higher Low) : creux plus haut que le précédent → confirmation uptrend
  • LH (Lower High) : sommet plus bas que le précédent → structure baissière
  • LL (Lower Low) : creux plus bas que le précédent → confirmation downtrend

Identifier les swings significatifs

Tous les sommets et creux ne sont pas égaux. En ICT, on distingue :

  • Swing High/Low majeur : clairement visible, avec plusieurs bougies de chaque côté. Ce sont ces niveaux qui définissent la structure.
  • Swing High/Low mineur : petites fluctuations à l'intérieur d'un mouvement — pertinents pour les entrées LTF, pas pour la structure HTF.

La structure sur plusieurs timeframes

  • Weekly/Daily : structure macro — définit le biais long terme
  • H4/H1 : structure intermédiaire — définit le biais de la semaine/journée
  • M15/M5 : structure d'exécution — permet de trouver l'entrée précise
Règle d'or : ne jamais trader contre la structure du timeframe supérieur. Un signal d'achat sur le M15 dans un contexte Daily baissier est un signal à ignorer.

Lire la structure en pratique

  1. Ouvrez le graphique Daily ou H4
  2. Identifiez le dernier swing high et swing low significatifs
  3. Tracez mentalement la direction : HH/HL = haussier ; LH/LL = baissier
  4. Demandez-vous : "Quel niveau doit être cassé pour invalider cette structure ?"
  5. Descendez sur H1 ou M15 pour chercher vos setups dans la direction de cette structure
