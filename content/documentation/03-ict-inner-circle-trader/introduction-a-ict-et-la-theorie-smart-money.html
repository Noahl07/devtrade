Qui est ICT ?

Michael Huddleston, connu sous le pseudonyme ICT (Inner Circle Trader), est un trader et formateur américain qui a développé une méthodologie basée sur le comportement des institutions financières. Ses enseignements, diffusés gratuitement sur YouTube depuis 2012, ont révolutionné l'approche du trading retail en exposant les mécanismes réels derrière les mouvements de prix.

La prémisse fondamentale

La théorie Smart Money repose sur un constat simple :

  • Les banques, hedge funds et algorithmes représentent 95%+ du volume sur les marchés majeurs
  • Ces acteurs ont besoin de liquidité massive pour placer et sortir leurs positions
  • Les traders retail, en plaçant leurs stop-loss de façon prévisible, créent cette liquidité
  • Les institutions engineèrent des mouvements pour aller chercher cette liquidité avant de partir dans la vraie direction

  • Support/résistance visibles par tous → stop-loss regroupés → cible facile pour les institutions
  • Cassures de supports → vente → les institutions achètent cette liquidité pour leur long
  • Indicateurs standards (RSI surachat → vente) → les institutions continuent d'acheter
Une fois que vous comprenez comment les institutions opèrent, vous pouvez trader avec elles plutôt que contre elles. C'est exactement ce qu'enseigne la méthodologie ICT.

Les 6 piliers de la méthodologie ICT

  1. Structure de marché — identifier qui contrôle le marché (HH/HL/LH/LL)
  2. Liquidité — comprendre où se trouvent les stops et comment ils seront chassés
  3. Order Blocks — zones où les institutions ont placé leurs ordres massifs
  4. Fair Value Gaps — inefficiences de prix que le marché revient combler
  5. Kill Zones — fenêtres temporelles où les mouvements institutionnels se produisent
  6. Premium & Discount — acheter dans les zones de valeur, vendre dans les zones de prime
