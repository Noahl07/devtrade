Le coût invisible qui détruit la plupart des traders débutants

On vous apprend à analyser les marchés, à placer des ordres, à gérer votre risque. Mais rarement on vous explique combien vous coûte réellement chaque trade. Pourtant, les coûts de trading sont l'un des facteurs les plus déterminants dans la rentabilité à long terme. Un système gagnant sur le papier peut devenir perdant en réel si les coûts ne sont pas maîtrisés.

Le spread — le coût le plus visible

Le spread est la différence entre le prix Ask (prix auquel vous achetez) et le prix Bid (prix auquel vous vendez). C'est la première barrière que vous franchissez à chaque trade — vous êtes immédiatement en négatif dès l'ouverture.

Le spread est exprimé en pips (Forex) ou en points (indices/matières premières). Exemples typiques :

  • EUR/USD : 0.1 à 0.5 pip (très liquide)
  • GBP/USD : 0.5 à 1 pip
  • XAU/USD (Gold) : 20 à 50 points
  • NAS100 : 0.5 à 2 points selon broker
  • Paires exotiques : 5 à 50 pips — le piège des débutants

Les deux modèles de tarification broker

1. Compte Market Maker (sans commission)
Le broker se rémunère uniquement via le spread — plus large qu'en ECN. Convient aux petits comptes.

2. Compte ECN/Raw Spread (avec commission)
Le spread est quasi-nul (0.0 à 0.1 pip) mais vous payez une commission fixe par lot. Exemple typique : 3.5€ aller + 3.5€ retour = 7€ total pour 1 lot d'EUR/USD.

Le swap — le coût des positions overnight

Le swap est un intérêt crédité ou débité sur vos positions maintenues ouvertes au-delà de 17h00 ET. Il reflète le différentiel de taux d'intérêt entre les deux devises.

  • Certaines positions génèrent un swap positif (vous gagnez des intérêts)
  • D'autres génèrent un swap négatif (vous payez) — le cas le plus fréquent
  • Le mercredi, le swap est triplé pour compenser le week-end

Le slippage — le coût imprévisible

Le slippage est la différence entre le prix voulu et le prix d'exécution réel. Il se produit en période de forte volatilité (news, ouverture de session). Exemple : vous visez 1.08450, votre ordre s'exécute à 1.08458 — vous avez perdu 0.8 pip sans le vouloir.

Pour limiter le slippage : préférer les ordres limites aux ordres au marché, et éviter d'entrer sur les news majeures.

Calculer votre breakeven réel

Breakeven = Spread + Commission (en pips) + Slippage moyen

Sur EUR/USD ECN (0.1 pip spread + 0.7 pip commission + 0.1 pip slippage) : Breakeven = 0.9 pip. Chaque trade doit faire au minimum 0.9 pip dans votre direction avant d'être profitable.

Comment choisir son broker selon les coûts

  • Scalping/Day trading : Broker ECN avec commissions basses (Pepperstone, IC Markets)
  • Swing trading : Le spread importe moins, privilégier la régulation et le swap
  • Débutant : Commencer sur démo pour mesurer les vrais coûts avant le réel
  • Toujours vérifier : Les brokers régulés (FCA, ASIC, CySEC) affichent leurs conditions clairement

Réduire vos frais de 0.2 pip par trade peut représenter plusieurs centaines d'euros de gain annuel sur un compte actif. Un bon trader surveille ses coûts comme un chef d'entreprise surveille ses charges fixes.
