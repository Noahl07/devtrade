Le Spring et l'Upthrust — les moments de vérité

Parmi tous les événements du cycle Wyckoff, le Spring et l'Upthrust sont les deux moments les plus tradables et les plus significatifs. Ils représentent le dernier piège du Composite Man avant de lancer le vrai mouvement — et donc l'opportunité d'entrée idéale pour le trader informé.

Ces deux concepts sont directement liés à ce qu'ICT appelle les "liquidity sweeps" — la terminologie a changé, mais la mécanique est identique. Wyckoff les a décrits 80 ans avant ICT.

Le Spring — le piège baissier en accumulation

Le Spring se produit dans un range d'accumulation. Après plusieurs semaines de consolidation, le prix descend brusquement sous le bas du range — "cassant le support" selon l'analyse technique classique. Cette cassure déclenche :

  • Les stop-loss des traders qui avaient acheté dans le range
  • Les entrées vendeurs des traders en cassure de support
  • La panique psychologique des acheteurs restants

Mais immédiatement après, le prix se retourne et remonte dans le range. Le Composite Man a utilisé ces ordres de vente comme liquidité pour acheter massivement à des prix encore meilleurs.

Les trois types de Spring

Wyckoff identifiait trois variantes selon la profondeur de la cassure :

  • Spring Type 1 : cassure significative sous le support, fort volume, rebond rapide. Le plus visible et le plus fiable.
  • Spring Type 2 : cassure modérée sur volume moyen. Moins dramatique mais tout aussi valide.
  • Spring Type 3 : simple test du support sans cassure, sur faible volume (No Supply). Le plus subtil — indique que les vendeurs sont épuisés même sans vrai Spring.

Confirmation du Spring — ne pas entrer prématurément

L'erreur classique est d'entrer dès que le Spring se produit. La confirmation vient de :

  • Rebond rapide dans le range sur volume supérieur à la descente du Spring
  • Formation d'un LPS (Higher Low par rapport au Spring) — premier signe de structure haussière
  • Volume décroissant sur les pullbacks post-Spring — No Supply
  • SOS (Sign of Strength) : premier break au-dessus du range sur gros volume

L'Upthrust — le piège haussier en distribution

L'Upthrust est le symétrique exact du Spring mais dans un range de distribution. Après une phase d'accumulation et de markup, la distribution crée un range latéral au sommet. L'Upthrust est la cassure fausse au-dessus du range.

LPSY — Last Point of Supply

L'équivalent du LPS pour la distribution. Après l'Upthrust et le retour dans le range, le prix fait un rallye anémique sur faible volume — le dernier LH avant le markdown. C'est la zone d'entrée short idéale.

Spring/Upthrust vs ICT Stop Hunt — les similitudes

La correspondance est parfaite entre les concepts Wyckoff et ICT :

  • Spring = SSL Sweep (sell-side liquidity grab) + retournement haussier
  • Upthrust = BSL Sweep (buy-side liquidity grab) + retournement baissier
  • LPS = premier HL après CHoCH haussier (ICT)
  • LPSY = premier LH après CHoCH baissier (ICT)
  • SOS = BOS haussier après Spring (ICT)
  • SOW = BOS baissier après Upthrust (ICT)

ICT n'a pas inventé ces concepts — il les a reformulés avec un vocabulaire moderne et les a intégrés dans un framework cohérent. Comprendre Wyckoff vous donne la profondeur historique et analytique que le vocabulaire ICT seul ne peut pas fournir.
